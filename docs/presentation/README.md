# Legal AI Copilot — Presentation Documentation

Documentação completa para a produção do vídeo de apresentação do Legal AI Copilot.

Este pacote cobre todo o ciclo: planejamento, gravação de tela, narração, edição, assets visuais e validação final. O vídeo é composto exclusivamente por **gravação de tela**, **cursor do mouse** e **narração em off** — sem webcam, sem apresentador.

## Convenções

### Nomenclatura de Arquivos

| Padrão | Exemplo | Significado |
|--------|---------|-------------|
| `NN_DOCUMENTO.md` | `02_DEMO_TIMELINE.md` | Documentos numerados sequencialmente na raiz |
| `assets/NN_ASSET.md` | `assets/01_TITLE_CARDS.md` | Assets numerados sequencialmente na subpasta |
| `README.md` | `README.md` | Índice principal (este arquivo) |

### Numeração de Cenas

- As cenas são numeradas de **01 a 14** em toda a documentação
- A numeração é consistente entre todos os documentos
- Cena 01 = Abertura, Cena 14 = Encerramento
- Referências cruzadas usam o formato "Cena NN"

### Referências de Tempo

- Formato: `MM:SS` (ex: `02:30`) ou `HH:MM:SS` (ex: `00:12:30`)
- Tempos baseados no `02_DEMO_TIMELINE.md` como fonte de verdade
- Tolerância de ±30s em relação ao tempo alvo

### Assets Visuais

- Todos os assets são especificações em Markdown (não arquivos binários)
- O editor cria os elementos visuais no software de edição seguindo as especificações
- Cores referenciadas em hex (ex: `#2563EB`) extraídas do TailwindCSS da aplicação
- Ícones referenciados pelo nome em `lucide-react`

### Idioma

- Documentação técnica: Português (BR)
- Textos overlaid no vídeo: Inglês (títulos, lower thirds, end credits)
- Narração: Português (BR)
- Textos da aplicação: Mistos (PT/EN conforme implementado)

## Atualização

Caso novas funcionalidades sejam adicionadas ao Legal AI Copilot no futuro, a documentação da apresentação deve ser atualizada seguindo este processo:

### 1. Identificar Impacto

Verificar quais documentos são afetados pela nova funcionalidade:

- Nova tela ou rota? → Atualizar `03_SCREEN_NAVIGATION_SCRIPT.md` e `11_SCREEN_RECORDING_SHOTLIST.md`
- Nova fala necessária? → Atualizar `04_VIDEO_SPEECH_SCRIPT.md` e `assets/08_NARRATION_PACING.md`
- Novo elemento visual? → Atualizar `assets/03_SCREEN_CALLOUTS.md` e `assets/07_ICON_REFERENCE.md`
- Nova cor ou badge? → Atualizar `assets/06_COLOR_REFERENCE.md`
- Mudança na timeline? → Atualizar `02_DEMO_TIMELINE.md` primeiro (fonte de verdade)

### 2. Ordem de Atualização

```
02_DEMO_TIMELINE.md (fonte de verdade temporal)
        ↓
03_SCREEN_NAVIGATION_SCRIPT.md (navegação)
        ↓
04_VIDEO_SPEECH_SCRIPT.md (narração)
        ↓
11_SCREEN_RECORDING_SHOTLIST.md (gravação)
        ↓
10_VIDEO_EDITING_SCRIPT.md (edição)
        ↓
assets/* (elementos visuais)
        ↓
assets/09_VIDEO_QUALITY_CHECK.md (validação)
        ↓
README.md (este índice)
```

### 3. Validação

Após atualizar:

- [ ] Todos os tempos continuam consistentes entre documentos
- [ ] Nenhuma cena nova foi adicionada sem atualizar a timeline
- [ ] Nenhuma URL inventada — verificar em `frontend/src/App.tsx`
- [ ] Nenhum botão inventado — verificar no componente React correspondente
- [ ] Nenhuma cor inventada — verificar no TailwindCSS do componente
- [ ] Nenhum ícone inventado — verificar import de `lucide-react`
- [ ] README.md atualizado se novos documentos foram criados

### 4. Versionamento

- Commit message: `docs: update presentation documentation for [funcionalidade]`
- Sempre manter a numeração sequencial (não renumerar documentos existentes)
- Novos documentos recebem o próximo número disponível
