# Title Cards — Legal AI Copilot

> Títulos que aparecem sobrepostos na tela durante o vídeo.
> Estilo: minimalista, discreto, fade in/out suave.
> Referência: Stripe, Vercel, Linear, OpenAI.

---

## Especificações Técnicas Gerais

| Parâmetro | Valor |
|-----------|-------|
| Fonte | Inter Bold (título) / Inter Regular (subtítulo) |
| Cor do título | #FFFFFF |
| Cor do subtítulo | #94A3B8 (slate-400) |
| Sombra | 2px offset Y, 4px blur, #000000 70% |
| Animação de entrada | Fade in 0.5s |
| Animação de saída | Fade out 0.5s |
| Posição | Centro horizontal, 15% da altura a partir do topo |
| Safe area | 80px de margem lateral mínima |
